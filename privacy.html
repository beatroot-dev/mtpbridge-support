Privacy Policy

Effective date: 20 October 2026 · App version 1.0

File transfers

MTPBridge transfers files directly between your Mac and a connected USB MTP device. It does not upload your files to the developer or a cloud service. The app has no account system, advertising, tracking or embedded analytics.

Data stored on your Mac

The app stores your selected-folder access permission and folder location, the last selected device storage and an initial folder-prompt preference. These settings remain on your Mac.

The app creates a local diagnostic log that can contain device names, file names, paths, error details and operation timestamps. It keeps the current log and may rotate it to a previous log when the current file is over 2 MB at app startup. Logs are not sent automatically.

Downloads may use local temporary files; dragging a file from the device into Finder can create a temporary local copy before moving it to the chosen destination. The app attempts to remove these temporary files when the operation finishes or fails. A crash can leave temporary data behind.

Support email

Choosing Report a Bug opens a draft in your email app with the app version, build, macOS version and a description template. The draft does not include a log attachment automatically. You can edit or discard it.

If you send an email, support receives your sender address, message and any attachments you choose to include. We use this information to respond and investigate the reported problem, not for advertising or tracking. Email is handled by your email provider and our iCloud Mail service. We retain correspondence only as needed for support and related obligations. You can ask about access to or deletion of your correspondence at beat.root.dev@icloud.com.

Permissions and control

You choose which Mac folder the app can access and which files to transfer. You can select a different folder at any time. App settings, local logs and app temporary files are stored in its macOS container. Removing app data does not remove files you copied to other folders or the connected device.

This website

This static website has no analytics scripts, advertising, contact forms or embedded third-party resources. When this site is served through GitHub Pages, GitHub logs and stores visitors' IP addresses for security, under the GitHub Privacy Statement. See GitHub Pages data collection. This website's hosting is separate from USB transfers in the app.

Updates and contact

We will update this page if these practices change. Questions: beat.root.dev@icloud.com.
